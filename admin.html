What "remove" does

Removing deletes the profile row, which revokes all access immediately. It does not delete the underlying login — that requires a privileged key which deliberately does not exist anywhere in this site. To erase an account completely, delete the user in the Supabase dashboard under Authentication → Users.

A removed person can sign up again with the same address and will land back at pending.

Invite codes

A code promotes whoever redeems it straight to member, so you do not have to approve them by hand. Codes can never grant admin — the database function that redeems them only ever writes member.

CodeLabelUsedExpiresStatus
Treat a code like a password

Anyone holding it can let themselves in, so send it directly rather than posting it anywhere public. Codes are long enough that guessing one is not realistic, but there is no rate limiting behind them — that length is the whole defence, so do not shorten them.

Revoking kills a code immediately. It does not remove anyone who already used it; change their role in the accounts table above for that.

Embedding does not make a video private

The video plays from YouTube's servers, so the permissions on this site have no reach over it. Use unlisted videos: they stay out of search and off your channel, but anyone who finds the URL — and it is visible in this page's source to anyone signed in — can watch it on YouTube directly.

Attachment links are the same. Whatever sits at the far end is governed by that service, not by member roles here. A publicly shared Drive file stays public.

Import

A broker export or your own spreadsheet, straight into the journal. Any column layout works — you say which column means what, and nothing is written until you have seen what it read.

What it accepts

CSV, TSV, and Excel workbooks (.xlsx and the older .xls). The columns can be named anything and sit in any order. Common names are recognised on sight — a column called Qty, Quantity, Size or Contracts all land on quantity — and anything not recognised you set by hand from a dropdown.

Three columns are needed: when the trade opened, what you traded, and which way. Everything else is optional. A file carrying only those three and a profit figure still produces a working calendar and a usable set of statistics, which is the point — most broker statements do not give you a stop price, and waiting for one would mean importing nothing.

Start from the template if you keep your own records

It has the column names already in place, so nothing needs mapping. Fill in the rows, delete the two examples, and import it.

Bringing a file out of a platform

Every one of these exports round turns — a row per completed trade — which is the shape this page expects. An export of individual fills imports too, but each fill arrives as its own trade.

Tradovate
Desktop client, the dropdown with your account name, the gear icon, Account reports, set a date range, Download Report. Use the Performance export rather than the dashboard summary. It carries its own fill identifiers, so re-importing an overlapping range corrects those trades instead of duplicating them.
R|Trader Pro (Rithmic)
The completed orders view, right-click, export. It lists fills rather than round turns, so expect to tidy up afterwards.
TradingView
Paper or broker account, the Trading panel, History, then the export icon. One tab exports at a time.
NinjaTrader
Control Center, Trade Performance, run a report, right-click the grid, Export.
Anything else
If it produces a spreadsheet with one row per trade, it will import. Match the columns by hand once and check the preview.
Which account the trades belong to

If your file has an account column, map it and each row keeps its own. If it does not — most exports do not name the account they came from — set one below and it applies to the whole file. With several copied prop accounts that means one export and one import each, which is worth doing: the account that behaves differently from its copies is the only one telling you anything.

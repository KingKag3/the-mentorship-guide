Import

A broker export, straight into the journal. Nothing is written until you have seen what it read — and importing the same range twice updates those trades rather than doubling them.

Tradovate

Desktop client → the dropdown with your account name → the gear icon → Account reports → set your date range → Download Report.

One file per account

The export does not say which account it came from, so the account is set here rather than read from the file. With several copied accounts that means one export and one import each — which is worth doing, because the account that behaves differently from its copies is the only one telling you anything.
